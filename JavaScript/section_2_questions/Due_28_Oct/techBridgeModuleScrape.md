# Let's practice scraping

- Scrape the Techbridge website <https://bootcamps.cs.cmu.edu/coding-bootcamp/>, gathering all the h2 elements.
- Create an object mapping all the module names to their description from the heading.
  e.g.`{M7: "Full-Stack Integration"}`
- Print that object. No problem if there is some extra whitespace (newlines, spaces, tabs) inside the module description.
