# CMU Boot Camp Repository

## Overview
This repository contains all my coursework and projects from the CMU TalentSprint coding boot camp. It showcases my journey and learning progress in web development and programming fundamentals.

## Course Modules

1. **Getting Started**
   - Overview of the course and initial setup.

2. **Programming Fundamentals and Applications with Python**
   - Basics of Python programming, including syntax, control structures, and data manipulation.

3. **Foundational Web Development with HTML and CSS**
   - Designing and structuring web pages using HTML and styling them with CSS.

4. **Frontend Development with React**
   - Building interactive and dynamic web applications using React.js.

5. **Backend Development: Databases, Authentication & APIs**
   - Introduction to server-side programming, working with databases, implementing authentication, and building APIs.

6. **Full Stack Integration**
   - Combining frontend and backend technologies to create complete web applications.

7. **Cloud Deployment & DevOps**
   - Learning about cloud services and deploying applications, with a focus on DevOps practices. *(Coming Soon)*

8. **Capstone Projects**
   - Final projects integrating all acquired skills to build comprehensive applications. *(Coming Soon)*
